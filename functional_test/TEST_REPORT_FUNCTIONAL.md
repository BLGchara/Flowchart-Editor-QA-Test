# 功能测试报告 (Functional Test Report)

## 1. 测试概述

### 1.1 测试目的
验证 Flowchart Editor 应用的各项功能是否按照预期正常工作，确保用户能够正常使用流程图编辑器的所有核心功能。

### 1.2 测试范围
涵盖流程图编辑器的主要功能模块，包括但不限于：
- 节点创建与管理
- 连接线功能
- 流程图保存与加载
- 用户界面交互
- 数据处理功能

## 2. 测试环境

### 2.1 硬件环境
- 处理器: Intel Core i5 或同等性能处理器
- 内存: 8GB RAM
- 存储空间: 至少100MB可用空间

### 2.2 软件环境
- 操作系统: Windows 10/11, macOS 10.15+, Ubuntu 20.04+
- 浏览器: Chrome 最新版本, Firefox 最新版本, Edge 最新版本
- Node.js: v14.x 或更高版本
- npm: v6.x 或更高版本
